# MSDS422: Practical Machine Learning
Here you can find the progression of my curriculum from my MSDS422: Practical Machine Learning class as part of my masters in data science pathway at Northwestern. I've provided the final assignment that combines all of the work from previous assignments as an example of my work.

Rather than treating assignments as isolated tasks, the course simulates a real-world end-to-end data science workflow, applying increasingly sophisticated modeling techniques to a consistent business case and dataset.

**Environment**: Jupyter Notebook

**Languages**: Python and Markdown

**Core Libraries**: `pandas`, `numpy`, `math`, `tensorflow`, `matplotlib`, `seaborn`, `sklearn`, `mlxtend`

## Project Progression

Assignment 1: Exploratory Data Analysis (EDA), handling missing values, feature scaling, and encoding categorical variables

Assignment 2: Implementing and tuning Decision Trees, Regression Trees, Random Forests, and Gradient Boosting.

Assignment 3: Developing regression models using various variable selection methods to optimize predictive power.

[Assignment 4](https://github.com/LidaTetyu/ML-Projects/blob/MSDS-422-Practical-Machine-Learning/MSDS422%20Assignment%204%20Lida.pdf): Training a multi-layer neural network using TensorFlow
